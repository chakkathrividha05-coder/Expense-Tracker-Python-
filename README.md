# Expense-Tracker-Python-
Expense Tracker is a simple Python-based application designed to help users record and manage their daily expenses efficiently. The system allows users to add expenses, view all recorded expenses, calculate the total amount spent, and delete unwanted expense entries. it provides a user-friendly menu-driven interface that makes expense management easy and organized. the project is developed using basic python programming concepts such as lists, dictionaries, functions, loops and conditional statements. It serves as a practical application of python fundamentals and helps users understand how programming can be used to solve real world problems. This project is particularly useful for students and beginners who want to learn how to store, process, and display data in a structured manner. by maintaining a record of expenses, users can monitor their spending habits and make better financial decisions.
key features
add new expense records
view all saved expenses
calculate total expenditure
delete existing expense entries
simple menu-driven interface
benefits
easy to use and understand
helps track daily expenses
demonstrates core python concepts
